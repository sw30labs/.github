# Lightweight research repository template

Copy this directory only when starting or deliberately updating a research project. Adapt to existing layout; do not move old code merely to match a template.

1. Replace this README with the research question, maturity, current experiment, actual findings (or “no results yet”), reproduction entry point and limitations.
2. Complete RESEARCH.md before a confirmatory run.
3. Give each experiment a stable ID, store its protocol under experiments/, and write raw evidence separately from interpretation under results/.
4. Link back to the Research Atlas. Record negative findings and the next decision.

Build a chapel, not a cathedral. We optimize for the rate at which ideas become evidence. Failure is a result.
