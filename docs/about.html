The tools behind the research practice.
Each layer has a job to do.

01

The machines

NVIDIA DGX Spark

Local compute for development, inference and experiments. Hardware capacity is an input; useful accepted work is the outcome.
02

The model layer

oMLX / MLX
Local Spark serving · Ollama

Local model serving for agent workloads and private-content processing. Model selection follows the job and available capacity.
03

The working language

Python · LangGraph
Deterministic scripts and tests

Graphs where stateful agent work needs them. Small standard-library experiments where a simpler tool answers the question.
04

Memory and context

TwinOps · MCP
Neo4j · Snapshot data

Retrieve relevant background with provenance. Live graph queries and saved snapshots have different freshness; neither overrides current decisions.
05

Observe and assess

Loopscope · DriftLab
OSCAL Skills Guardrails

Execution traces, behavioral-drift research and skill-admission evidence. Complementary instruments, with different scopes and integration maturity.
06

Deliver and decide

GitHub · Nightshift
GrokBot / Morning Prayers

Versioned artifacts and reviewable branches, followed by human decisions. Accepted evidence feeds the next portfolio review.

A working stack, not a claim that every tool is connected to every other tool. The map above distinguishes implemented connections from intended handoffs. Specific models and configurations change with the experiment.
